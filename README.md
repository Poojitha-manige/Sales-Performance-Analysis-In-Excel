 Sales Performance Dashboard (Excel Project)

 Project Overview

This project is an interactive **Sales Performance Dashboard** built in Microsoft Excel using a 500-record dataset.

The goal of this project is to analyze sales data and visualize business performance using:

- Pivot Tables
- Pivot Charts
- KPI Cards
- Slicers (Interactive Filters)

This project is designed for beginners who want to practice real-world Excel dashboard skills.

---

 Dataset Information

**File Name:** `excel_dashboard_dataset_500_records.csv`

**Number of Records:** 500

### Columns Included:

- Order_ID
- Order_Date
- Region
- Product
- Sales_Rep
- Quantity
- Unit_Price
- Total_Sales

---

 Dashboard Objectives

The dashboard answers important business questions:

- What is the total revenue?
- Which region performs best?
- Which product generates the most sales?
- Who is the top sales representative?
- What is the monthly sales trend?

 How to Use This Project

1. Open the CSV file in Excel.
2. Convert data into a Table (Ctrl + T).
3. Create Pivot Tables.
4. Insert charts from Pivot Tables.
5. Add KPI formulas.
6. Insert slicers for filtering.
7. Design the final dashboard layout.
